# 2026-10-22: Dark mode

Issue: #207 · Branch: `feat/207-dark-mode`

## Context

The theme has been light only since #28, when an automatic
`prefers-color-scheme` dark mode showed a black page on the owner's
dark-mode phone. The owner now asked for a configurable dark mode across
the app and landing page.

## Done

- `src/ui/theme.js`: preference `settings.theme` = `light` (default) |
  `dark` | `system`. Sets `data-theme` on `<html>` and keeps the
  `theme-color` and `color-scheme` metas in step; follows the device live
  while System is chosen.
- `index.html`: a small inline script reads the saved setting and sets
  `data-theme` before first paint, so dark never flashes light.
- Settings → Preferences → **Appearance** select (Light / Dark / Match
  device), in the en, lg, sw and fr UI packs.
- `tokens.css`: new semantic tokens (`border-strong`, `divider`,
  `surface-raised`, `outline`, `block`, `block-soft`, `primary-soft`,
  `success-text`, `error-text`) replace the raw paper/ink tokens that
  component CSS used directly, and a `:root[data-theme='dark']` block
  redefines the semantic tokens with warm promada ink/paper. Light mode
  renders as before.
- Tests: `tests/theme.test.js`; `e2e/theme.spec.js` (light default on a
  dark device, dark applied before app code, System follows the device,
  the setting saves, axe passes on the dark landing page and ten screens).

## Decisions

- Light stays the default; System is opt-in only (the #28 lesson).
- The raw palette (`--color-paper-*`, `--color-ink-*`) never changes, so
  illustrations and anything sitting on gold or a light pastel keep their
  printed look. Only semantic tokens switch.
- Character art, avatar backgrounds and story cards keep their light
  pastels in dark mode (they read as printed stickers); UI pastels (unit
  banners, selected tiles, cards) deepen so light text stays readable.
- Vermillion stays the brand colour; vermillion text on dark uses the
  lighter `vermillion-300`.
- Luganda strings (Endabika, Kitangaala, Kizikiza, Nga ekyuma kyo) join the
  native-speaker review list.

## Next
