# Development journal

This folder is Claude's development log for Learn Luganda. It is not a
user-facing feature of the app.

Each entry records what was done, the decisions made and why, and what comes
next. A new entry is added with every pull request.

## Conventions

- One file per entry, named `YYYY-MM-DD-short-slug.md`.
- Sections: **Context**, **Done**, **Decisions**, **Next**.
- Reference the issue and PR the work belongs to.
