# 2026-10-21: Weekly leagues (local)

Issue: #20 · Branch: `feat/20-leagues`

## Context

Duolingo's leagues make XP social. Learn Luganda has no server, so the
league is a practice league: the rivals are simulated on the device and
the page says so. The learner's own XP is real.

## Done

- **Simulation** (`src/state/league.js`): 14 rivals per week and tier,
  generated from a hash of `week:tier`, so a week always shows the same
  names, avatars and pace. Rival XP is built day by day from a seeded
  roll (rest days, normal days, the odd big day) and grows smoothly
  through the current day, so standings move while you watch but never
  go backwards. Rivals get keener in higher tiers.
- **Tiers**: Bronze, Silver, Gold, Sapphire, Ruby, Emerald, Diamond. Top 5
  promote, bottom 3 demote (none from Bronze, none above Diamond). A week
  with 0 XP never promotes and drops a tier above Bronze.
- **Week rollover**: `settleLeague` runs on app start and on the page.
  It joins Bronze on first visit, then closes any finished week using the
  final standings, records history (last 26 weeks) and leaves a
  `pendingResult` that the page announces once in a modal.
- **Page** (`/leagues`): tier strip with shields, time left, your rank,
  ranked table with promotion and demotion zone dividers, an empty-state
  nudge when you have no XP yet, and a note that rivals are simulated.
- Shield colours stay inside the brand palette (ink, greys, vermillion,
  gold) per the light-only theme rule.
- New icons: `up`, `down`, `info`.
- 7 new tests: deterministic rivals, monotonic rival XP, weekly XP window,
  ranking, promotion on rollover, demotion when inactive, zones.

## Decisions

- Ties go to the learner, so a learner never loses a place on a tie.
- Rollover uses the week's last millisecond for rival XP, so the result
  matches the table the learner saw at the end of the week.
