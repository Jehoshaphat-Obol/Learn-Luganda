# 2026-10-22: French interface pack

Issue: #133 (epic #80, wave 1 of docs/languages/README.md) · Branch: `feat/133-french-ui`

## Context

French is the most widely read language in Central and West Africa (DRC,
Cameroon, Côte d'Ivoire, Senegal, Rwanda, Burundi). A French interface opens
the app to francophone learners now, and is the base for the Luganda
for French speakers (#144) and French for Luganda speakers (#145) courses.

## Done

- `src/packs/ui/fr.json`: every string of `ui/en.json` in French, informal
  "tu" as Duolingo uses, neutral vocabulary readable in Africa, Europe and
  Canada. French typography: a no-break space before ? ! : ; % and inside « ».
  Two extra praise lines (Chapeau !, Au top !) and a reminder built on the
  saying _Goutte à goutte, la mer se remplit_.
- French path headings (`labels/fr.json`) for all five courses, so the
  section, unit and skill titles follow a French interface.
- Grammar that a filled-in value changes, in `src/i18n/format.js`:
  - French elision: "le {language}" with "anglais" reads "l’anglais",
    "de {language}" reads "d’anglais" (le/la/de/que/je/ne/me/te/se before a
    vowel; not before h, so "le haoussa" stays).
  - A string that starts with a placeholder starts with a capital.
- `languageTitle(code)` for a language name standing alone (picker options,
  switcher sheet): French writes language names in lower case inside a
  sentence ("anglais"), but a button reads "Anglais".
- Tests: complete French pack, elision and capitals, French headings, and an
  e2e run with a `fr-CD` browser.

## Decisions

- `languageNames` in French are lower case, as French writes them in a
  sentence; capitals come from `languageTitle` and the sentence-start rule.
- "Streak" is _série_, "streak freeze" _gel de série_, "gems" _gemmes_,
  "hearts" _cœurs_, "checkpoint" _point de contrôle_, "guidebook" _guide_,
  "achievements" _succès_.
- The app name stays "Learn Luganda" (the brand).

## Noticed

- The landing's course-specific copy (why cards, cast bios, sample words,
  the "LESSON Nº 001" style captions) still comes from the course pack or
  markup in English. The "Landing page translation gaps" work moves it into
  UI packs; French needs those keys when it lands.
